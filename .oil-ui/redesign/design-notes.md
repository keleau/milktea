# 奶茶点单小程序 · 高级感重设计

## 方向
奶油纸本 / 焦糖印刷：保留奶油底、焦糖棕、所有图片位置；减少高饱和橘、重阴影和大圆角，改为纸面、细描边、低阴影、小圆角、衬线标题/数字与实色按钮。

## 约束
- 不改 script、请求参数、接口、图片位置与尺寸。
- 只改样式、配色、原生导航/tab 颜色与共享组件样式。
- 新增 `fronted/common/style/premium.css`，由 App.vue 全局引入；所有页面继承。

## 改动
- 全局 token：背景 `#F4EDE3`、卡片 `#FFFCF7`、主色 `#6F4B2E`、强调 `#B86A3B`（按钮用 `#9F552D`）、主文字 `#2C211A`。
- 卡片 24rpx、图片 14rpx、按钮/输入 12rpx、标签 4–6rpx；主操作深焦糖实色，次操作为细描边；价格/大数字用宋体或 Georgia。
- 去掉高饱和渐变按钮与登录光斑；首页活动条、会员卡、订单状态横幅使用深色块形成节奏。
- 共享组件 product-card / coupon-ticket / category-rail / paws 单独收敛。
- 原生 tabBar 与导航栏颜色同步。

## 评审
独立视觉评审查看 `shots/page.png` 后提出：圆角体系、按钮层级、商品卡阅读顺序、小字可读性、AI 输入区胶囊感。已对应调整：
- 统一小圆角体系；商品卡改为「茶名最大、价格收敛、选规格细描边」。
- 主操作/次操作分色分形；小字提升到 22–24rpx；按钮高对比。
- 会员卡使用真实头像（非剪影）并缩小深色面积；AI 输入/发送改为小圆角。
保留：奶油/焦糖关系、实拍饮品图、原有图片位置、衬线数字、小票虚线。
